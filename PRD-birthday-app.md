# PRD — Birthday App

## Суть продукта

Веб-приложение для отслеживания дней рождения. Пользователь добавляет контакты с датами рождения и получает своевременные напоминания. Приложение доступно из любого браузера, данные привязаны к аккаунту и синхронизируются между устройствами.

---

## Статус по версиям

### v1 — Готово ✅
- Список контактов с сортировкой по ближайшему дню рождения
- Добавление, редактирование, удаление контактов
- Для каждого контакта: имя, день/месяц, год (опционально)
- Отображение: знак зодиака, возраст, дней до дня рождения
- Выделение сегодняшних именинников
- Экспорт и импорт контактов (JSON)
- Браузерные уведомления (Web Notifications API) — только когда приложение открыто
- Хранение данных локально в IndexedDB (Dexie.js)

### v2 — Готово ✅
- Меню контакта и форма создания открываются по центру экрана
- Заметки для каждого контакта (идеи подарков, поздравления, увлечения и т.д.)
- Иконка блокнота рядом с именем, если есть заметка
- Настройки приложения (⚙):
  - Тёмный / светлый режим
  - Выбор за сколько дней приходят уведомления (2 нед / 1 нед / 3 дня / 1 день / в день рождения)
  - Выбор времени уведомлений
- Навигация: «Отмена» в форме редактирования и диалоге удаления возвращает в меню контакта
- Заметки сохраняются в экспорте/импорте

## v3 — Планируется 🔜

### 1. Деплой в интернет

Приложение должно быть доступно по публичному URL, а не только локально.

**Что нужно:**
- Фронтенд: деплой на Vercel или Netlify (React/Vite)
- Бэкенд: Node.js / Express сервер (или аналог)
- База данных: PostgreSQL или MongoDB в облаке (Railway, Supabase, Atlas)
- HTTPS по умолчанию

---

### 2. Аккаунты пользователей

Каждый пользователь имеет свой личный список контактов.

**Регистрация и вход:**
- Email + пароль
- Или OAuth через Google / Telegram

**Безопасность:**
- Пароли хранятся в хэшированном виде (bcrypt)
- Авторизация через JWT-токены
- Refresh-токены для долгосрочной сессии

**UX:**
- Экран входа / регистрации при первом открытии
- После входа — сразу список контактов
- Выход из аккаунта в настройках

---

### 3. Синхронизация контактов

Контакты хранятся на сервере и автоматически подгружаются при входе.

**Поведение:**
- При входе в аккаунт — загрузка контактов с сервера
- Все изменения (добавление, редактирование, удаление, заметки) синхронизируются в реальном времени или при сохранении
- Контакты доступны с любого устройства
- Локальный IndexedDB используется как кэш для офлайн-доступа

**API (REST):**
- `GET /contacts` — получить все контакты пользователя
- `POST /contacts` — добавить контакт
- `PUT /contacts/:id` — обновить контакт
- `DELETE /contacts/:id` — удалить контакт

---

### 4. Уведомления через Telegram

Вместо браузерных уведомлений (которые работают только при открытом приложении) — уведомления приходят в Telegram в настроенное время.

**Как это работает:**
- Пользователь привязывает свой Telegram-аккаунт в настройках
- Для привязки: пользователь пишет `/start` нашему Telegram-боту, получает код, вводит его в приложении
- Сервер ежедневно в указанное время проверяет дни рождения и отправляет сообщения через Telegram Bot API

**Настройки уведомлений (сохраняются на сервере):**
- За сколько дней уведомлять (2 нед / 1 нед / 3 дня / 1 день / в день рождения)
- Время отправки (например, 09:00)

**Формат сообщения в Telegram:**
```
🎂 Завтра день рождения!
У Маши день рождения 19 марта. Приготовь поздравление!
```

**Технически:**
- Telegram Bot API (sendMessage)
- Cron-задача на сервере (node-cron или аналог): запускается раз в день в заданное время
- Хранение Telegram chat_id пользователя в базе
